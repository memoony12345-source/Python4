# نسّاق OCR — مشروع Android

هذا المستودع يحتوي على مشروع Android أصلي بلغة Kotlin.

## المزايا الموجودة في هذه النسخة
- اختيار صورة من ملفات الجهاز.
- التقاط صورة بالكاميرا (تُحفظ بجودة الكاميرا عندما يدعم تطبيق الكاميرا ذلك).
- استخراج النص محليًا باستخدام Tesseract مع بيانات العربية والإنجليزية.
- تحرير النص الناتج ونسخه ومشاركته.
- واجهة عربية واتجاه RTL.
- بناء APK تلقائيًا عبر GitHub Actions.

## إنشاء APK
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. افتح تبويب Actions.
3. اختر `Build NassakOCR APK`.
4. اضغط `Run workflow`.
5. بعد نجاح البناء افتح نتيجة التشغيل، ثم نزّل Artifact باسم `NassakOCR-debug`.
6. فك ضغط ملف Artifact لتحصل على `app-debug.apk`.

يمكن أيضًا تشغيل سير العمل تلقائيًا عند push إلى فرع `main`.

## ملاحظات مهمة
- تنزيل بيانات OCR للعربية والإنجليزية يتم أثناء GitHub Actions، ولا يلزم رفع ملفات اللغة الكبيرة يدويًا.
- هذه نسخة أولية قابلة للبناء للاختبار؛ يجب اختبار دقة OCR على صورك الفعلية قبل اعتبارها إصدارًا نهائيًا.
- لا تحتوي هذه النسخة بعد على موفر ذكاء اصطناعي سحابي أو شاشة لإدخال مفاتيح API. يمكن إضافة ذلك في مرحلة لاحقة بعد تحديد خدمة API المراد دعمها.
- بناء Debug APK لا ينتج تطبيقًا منشورًا على متجر Play ولا يتضمن توقيع إصدار Release.
